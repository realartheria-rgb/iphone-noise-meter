# iPhone Шумомер (Web App)

Простое веб-приложение-шумомер для iPhone. Использует микрофон телефона и Web Audio API для измерения уровня звука в децибелах (SPL, A-взвешивание — условное).

## Возможности
- Измерение уровня шума в реальном времени (дБ SPL, относительная калибровка).
- Отслеживание пикового значения.
- Спектральная визуализация (полоски по частотам).
- Полноэкранный режим (PWA-like): можно добавить на главный экран iPhone («На экран «Домой»»).
- Оптимизировано под iPhone: safe-area, viewport-fit, тач-кнопки, без зума.

## Как запустить на iPhone
1. Открой приложение в Safari (или размести на GitHub Pages — см. ниже).
2. Нажми «Старт» и разреши доступ к микрофону.
3. Для удобства: «Поделиться» → «На экран «Домой»» — появится иконка как у нативного приложения.

## Важно
- Показания **относительные** (калибровка по пику сигнета). Для юридически значимых или точных замеров нужен сертифицированный класс-прибор.
- Работает в Safari и Chrome на iOS при наличии доступа к микрофону и по HTTPS (или localhost).

## Технические детали
- `getUserMedia` для захвата микрофона.
- `AnalyserNode` (FFT 2048) для RMS и спектра.
- Чистый HTML/CSS/JS, без зависимостей и сборки.

## Локальный запуск
Открой `index.html` через локальный сервер с HTTPS (микрофон требует защищённый контекст):
```
npx serve .
```
или размести через GitHub Pages.
